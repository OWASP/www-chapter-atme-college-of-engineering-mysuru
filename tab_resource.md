# Resources

A curated set of resources for OWASP ATMECE chapter members — whether you're just starting out in application security or preparing for CTFs, bug bounty, or a career in cybersecurity.

## OWASP Official Resources

- **[OWASP Top 10](https://owasp.org/www-project-top-ten/)** — The standard awareness document for the most critical web application security risks.
- **[OWASP Testing Guide (WSTG)](https://owasp.org/www-project-web-security-testing-guide/)** — A comprehensive methodology for testing the security of web applications.
- **[OWASP Cheat Sheet Series](https://cheatsheetseries.owasp.org/)** — Concise, actionable guidance on specific application security topics.
- **[OWASP Juice Shop](https://owasp.org/www-project-juice-shop/)** — An intentionally insecure web application for practicing exploitation techniques.
- **[OWASP Mobile Application Security (MAS)](https://mas.owasp.org/)** — Standards and testing guide for mobile app security.
- **[OWASP API Security Top 10](https://owasp.org/www-project-api-security/)** — The top risks specific to APIs.
- **[OWASP DevSecOps Guideline](https://owasp.org/www-project-devsecops-guideline/)** — Integrating security into the DevOps pipeline.

## Practice Platforms & Labs

- **[TryHackMe](https://tryhackme.com/)** — Beginner-friendly, guided rooms covering web, network, and general security topics.
- **[Hack The Box](https://www.hackthebox.com/)** — Realistic labs and machines for hands-on offensive security practice.
- **[PortSwigger Web Security Academy](https://portswigger.net/web-security)** — Free, in-depth labs on web vulnerabilities, built by the makers of Burp Suite.
- **[PentesterLab](https://pentesterlab.com/)** — Exercises focused on real-world vulnerabilities.
- **[VulnHub](https://www.vulnhub.com/)** — Downloadable vulnerable VMs for offline practice.
- **[picoCTF](https://picoctf.org/)** — Beginner-friendly CTF platform run by Carnegie Mellon University.

## Essential Tools

| Tool | Purpose |
|---|---|
| [Burp Suite](https://portswigger.net/burp) | Web application proxy and vulnerability scanner |
| [Nmap](https://nmap.org/) | Network discovery and port scanning |
| [ffuf](https://github.com/ffuf/ffuf) | Fast web fuzzer for directories, parameters, and vhosts |
| [sqlmap](https://sqlmap.org/) | Automated SQL injection detection and exploitation |
| [XSStrike](https://github.com/s0md3v/XSStrike) | Advanced XSS detection and exploitation suite |
| [Nikto](https://cirt.net/Nikto2) | Web server vulnerability scanner |
| [Wireshark](https://www.wireshark.org/) | Network protocol analyzer |
| [Metasploit](https://www.metasploit.com/) | Exploitation framework |
| [OWASP ZAP](https://www.zaproxy.org/) | Free, open-source web app scanner |

## Learning & Certification Paths

- **[EC-Council Ethical Hacking Essentials / Coursera](https://www.coursera.org/)** — Foundational courses in ethical hacking and information security.
- **[HTB Academy](https://academy.hackthebox.com/)** — Structured learning paths, including the CPTS (Certified Penetration Testing Specialist) track.
- **[AWS Skill Builder](https://skillbuilder.aws/)** — Free training toward AWS security and cloud certifications.
- **[TCM Security Academy](https://academy.tcm-sec.com/)** — Affordable, practical courses on pentesting and OSINT.
- **[SANS Cyber Aces](https://www.cyberaces.org/)** — Free introductory security courses from SANS.

## Communities & Staying Current

- **[OWASP Local Chapters](https://owasp.org/chapters/)** — Connect with other OWASP chapters worldwide.
- **[Hacker News](https://news.ycombinator.com/)** — Tech and security news aggregator.
- **[The Hacker News](https://thehackernews.com/)** — Cybersecurity news and breach coverage.
- **[r/netsec](https://www.reddit.com/r/netsec/)** — Community-curated security research and write-ups.
- **[PayloadsAllTheThings (GitHub)](https://github.com/swisskyrepo/PayloadsAllTheThings)** — A massive collection of payloads and bypass techniques for web app pentesting.
- **[HackTricks](https://book.hacktricks.xyz/)** — Practical pentesting and CTF knowledge base.

## CTF & Bug Bounty

- **[CTFtime](https://ctftime.org/)** — Calendar and rankings for upcoming CTF competitions.
- **[HackerOne](https://www.hackerone.com/)** — Bug bounty platform with public programs to practice on.
- **[Bugcrowd](https://www.bugcrowd.com/)** — Another major bug bounty platform with a helpful researcher community.
